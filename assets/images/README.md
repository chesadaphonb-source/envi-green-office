# รูปภาพสำหรับเว็บไซต์ Green Office ENVI

วางไฟล์รูปที่ต้องการใช้กับเว็บไซต์ในโฟลเดอร์นี้ได้เลย

เว็บ GitHub Pages ใช้ `logo.png` ที่ผู้ใช้ส่งมาเป็นโลโก้ Green Office ENVI ในส่วนหัวทุกหน้าและไอคอนแท็บ แสดงเต็มภาพตามสัดส่วนเดิม ขนาดในส่วนหัว 96 × 96 พิกเซล และ 76 × 76 พิกเซลบนมือถือ ส่วน `KU copy.jpg` เก็บไว้สำหรับเว็บ Apps Script เดิม

ภาพด้านขวาของแบนเนอร์หน้าแรกใช้ `green-office-building.png` คัดลอกจากไฟล์ “รูป green office.png” ที่ผู้ใช้ส่งมา เป็นภาพวาดอาคารคณะขนาด 1536 × 1024 พิกเซล แสดงเต็มตามสัดส่วนด้วย `object-fit: contain` โดยไม่ตัดภาพหรือแก้ไฟล์ต้นฉบับ

เมื่อต้องการเปลี่ยนภาพหน้าแรก ให้นำ PNG ใหม่มาแทน `green-office-building.png` แล้วอัปโหลดการเปลี่ยนแปลงไป GitHub เช่นเดียวกับ `logo.png` ระบบ GitHub Actions จะนำรูปขึ้นเว็บพร้อมโค้ด

## รูปที่ใช้ได้ทันทีเมื่อได้รับไฟล์

- `faculty-logo.svg` หรือ `faculty-logo.png` — โลโก้คณะสิ่งแวดล้อมฉบับทางการ พื้นโปร่งใส ใช้ในส่วนหัวเว็บไซต์
- `university-logo.svg` หรือ `university-logo.png` — ตรามหาวิทยาลัยฉบับทางการ พื้นโปร่งใส หากต้องการแสดงร่วมกับโลโก้คณะ

สำหรับ PNG แนะนำไฟล์ต้นฉบับกว้างอย่างน้อย 512 พิกเซล และไม่มีขอบพื้นที่ว่างมากเกินไป ไม่ต้องใส่โลโก้ทั้งสองแบบหากมีเพียงแบบเดียว

## รูปประกอบเพิ่มเติม (ถ้ามี)

- ภาพอาคารหรือพื้นที่สีเขียวเพิ่มเติมเก็บไว้ที่นี่ได้ ภาพหน้าแรกปัจจุบันใช้ `green-office-building.png` แล้ว

ไอคอนทั้ง 7 หมวดใช้ SVG แบบเส้นที่ออกแบบให้เป็นชุดเดียวกันอยู่แล้ว จึงไม่จำเป็นต้องหารูปแยกสำหรับแต่ละหมวด

## การนำขึ้นเว็บ

เว็บ GitHub Pages ใช้ไฟล์รูปโดยตรงผ่าน `scripts/build-site.cjs` ซึ่งเลือกเฉพาะ `logo.png` และ `green-office-building.png` ไปเผยแพร่ การเปลี่ยนรูปบนเว็บใหม่นี้ไม่ต้องใช้ clasp

สำหรับเว็บ Apps Script เดิม:

โฟลเดอร์นี้เก็บรูปต้นฉบับในโปรเจกต์ รัน `node scripts/build-branding.cjs` จากโฟลเดอร์โครงการเพื่อบรรจุ `KU copy.jpg` เป็น `branding.html` สำหรับอัปโหลดขึ้น Apps Script รูปนี้จึงไม่ต้องมีเซิร์ฟเวอร์ฝากไฟล์แยก หากเปลี่ยนไฟล์ต้นฉบับต้องรันคำสั่งนี้ก่อนตรวจสอบและ push

ภาพหน้าแรกบรรจุด้วย `node scripts/build-hero-image.cjs` เป็น `hero-image.html` ในลักษณะเดียวกัน ไฟล์ PNG ต้นฉบับประมาณ 3.1 MB ถูกฝังทั้งไฟล์ตามที่ผู้ใช้ส่งมา
